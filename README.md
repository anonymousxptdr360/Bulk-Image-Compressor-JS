# Bulk Image Compressor (PNG & JPG)

A lightweight, fast, and secure web-based tool to compress multiple images locally in your browser. No server upload required, ensuring your privacy.

## 🚀 Live Demo
You can try the tool online here:
👉 [https://stopbordo.odoo.com/compresseur](https://stopbordo.odoo.com/compresseur)

## ✨ Features
* **Bulk Compression:** Upload and process multiple PNG and JPG files at once.
* **Client-Side Processing:** All compressions happen in your browser. Your images never touch a server.
* **Adjustable Quality:** Fine-tune the compression level with a real-time slider.
* **ZIP Export:** Download all compressed images in a single ZIP file using JSZip.
* **Modern UI:** Clean and responsive design built with Tailwind CSS.

## 🛠️ Technologies Used
* **HTML5 / CSS3**
* **Tailwind CSS** (via CDN)
* **JavaScript (ES6+)**
* **Canvas API** (for image processing)
* **JSZip** (for batch downloads)

## 💻 How to use locally
1. Download the [`vX.X.X-image-compressor.html`](https://github.com/anonymousxptdr360/Bulk-Image-Compressor-JS/releases) file.
2. Open it in any modern web browser (Chrome, Firefox, Edge, etc.).
3. Drag and drop your images and start compressing!
